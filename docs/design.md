# 小本账：范围和计算口径

给刚起步的小店、工作室记销售、费用和收付款。默认只在本机运行，账目保存在 SQLite；公开仓库只放代码和虚构例子。

## 这版做什么

- 销售：输入日期、项目、成交数量、单价、单位直接成本。
- 费用：记录房租、人工、水电等日常经营费用，不重复记销售中的直接成本。
- 收付款：与销售或费用关联，可以分次收、分次付，付款日与业务日分开。
- 概览：销售额、直接成本、毛利、日常费用、经营结余、收支、未收未付款，按日期筛选和按月查看。
- 更正：记录不可覆盖；错误记录作废后重记，保留作废原因。有关联流水时须先作废流水。
- 数据：销售/费用 CSV 预检与整批导入；CSV 导出；JSON 完整备份，只允许恢复到空账本。示例只能装入空账本。

不做：正式会计凭证、增值税及所得税、折旧、库存计价、进销存、发票、自动银行对账、贷款利息、多人权限、退款业务。作废用来改错，不是退款。数量目前限整数，适合按件、单、次汇总。金额均为人民币，不自动判断含税；使用者应统一口径。本版结果叫“经营结余”，不冒充法定净利润。

## 算法

销售额 = 数量 × 单价。直接成本 = 数量 × 单位直接成本。
毛利 = 销售额 − 直接成本。经营结余 = 毛利 − 日常费用。
业务按发生日期计入利润，现金按实际收付日期计入收支。
投入和取出资金仅影响收支，不影响经营结余。期初资金可记录为一笔资金投入。
未收款 = 截至截止日的销售额 − 对应已收款；未付款同理，包括销售直接成本和日常费用。
账面资金 = 从启用起累计已记收入 − 累计已记支出，不等于银行余额。
作废记录在所有报表中排除，因而作废会重算历史报告；这不是带锁账能力的审计系统。

基本术语参考 business.gov.au 的 [损益表说明](https://business.gov.au/finance/financial-tools-and-templates/set-up-a-profit-and-loss-statement) 和 [现金流说明](https://business.gov.au/finance/cash-flow/set-up-a-cash-flow-statement)。仅参考收入、成本、收支的区分，不实现其税务规则。

## 存储与安全

金额入参为十进制字符串，最多两位小数；内部用整数分，不用浮点数算账。单条总金额上限 100,000,000 元，数量 1..1,000,000。日期为 2000..2100 的真实 ISO 日期。
SQLite 事务内检查重复、付款余额和关联有效性，防止并发超付。限制导入 2 MiB / 2,000 行，完整备份恢复 10 MiB / 10,000 条。
无账号系统，只接受 loopback Host 和同源请求；所有写入需要自定义请求头。浏览器无第三方请求、字体、遥测，不连接模型服务。数据库未加密，备份包含全部账目，应自行妥善保管。

## 技术选择

Python 3.12 / FastAPI / SQLite；React + Vite 前端，构建后由同一个 FastAPI 服务提供。开发时 Vite 代理 /api。不引入 ORM、微服务或 LLM 来做四则运算。

替代方案：纯浏览器存储安装更省事但备份与数据约束较弱；云端多租户方便协作但需增加认证、隔离、运维。本版选本机单用户，把计算和数据安全先做好。
