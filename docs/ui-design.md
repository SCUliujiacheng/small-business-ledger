# 界面约定

概念图仅用于确定布局；README 使用真实运行截图。界面的文本、表格和计算都是程序渲染，不使用图片替代操作界面。

## 布局与组件

白底 #ffffff；浅灰侧栏 #f5f6f5；正文 #222b28；次要文字 #707974；线 #e3e6e3；主色 #326552；危险操作 #a63f35。6px 圆角、无投影、无渐变、无外部字体和图片。字体 system-ui / Microsoft YaHei / sans-serif；金额 ui-monospace tabular-nums；正文/控件 14px，标题 28px，区块标题 20px，主要金额 28px。
桌面侧栏 216px，主区域 padding 36px，最大内容宽 1440px。侧栏文本品牌“小本账”，无图标；四项导航；底部“本机账本”“人民币 · CNY”。移动端侧栏折为顶部横向导航，主区16px，金额条2x2，利润/收付上下排列，表格独立横滚。
概览顶部标题“经营概览”，副标题“先看利润，再看收付款。”；日期范围、主按钮“记一笔”。示例数据时显示“示例账本 · 以下为虚构数据”，真实空库不用假数值。
横向四金额区域：销售额、直接成本、日常费用、经营结余；细竖线分隔，不用四张悬浮卡。
下面65/35双栏：利润怎么算 / 收付款。细框表格，结余行淡绿；未收/未付清楚标“截至截止日”，账面资金说明“以已记流水为准，不等于银行余额”。下面最近记录表，再下方可放按月汇总表。
首屏允许副说明：经营结余未计算税费、折旧；不作为报税凭证。禁止新增宣传口号、虚构同比等指标。

## 必要扩展状态（与概念图同一套组件）

“记一笔”弹出原生dialog，销售/费用选项。销售字段日期、项目、分类、数量、单价、单位直接成本、备注；费用金额替代销售字段。显示准确的销售额/成本预览。保存后提示到收付款登记；不要默认假设已付款。dialog标签可访问、Escape关闭、保存中disabled、防重复提交。
销售与费用页：筛选类型/检索描述、日期、查看作废；表格日期/项目/类型/金额/已收已付/操作。详细行允许登记收付款或作废，作废必须非空原因。有关联有效流水时后端拒绝，UI显示具体错误。
收付款页：独立表单，种类选择、关联单据、日期、金额、备注；剩余可收可付可见；投入/取出无需关联单据。可作废流水，有明确确认步骤。
导入与备份：下载CSV模板、选择CSV文件、预检错误和有效行预览、确认导入；导出业务CSV和流水CSV；完整JSON下载、选择备份、确认仅空库恢复；加载虚构示例仅空库且需明确动作。备份包含全部账目/保管提醒。
空库：真实零值、“还没有记录，可以记第一笔，也可以载入示例账本。”；保留主操作。
这些状态是用户记账工作流必需，不另造营销区或装饰图。
